# Changelog

All notable changes to Grain. Versions follow [Semantic Versioning](https://semver.org); entries are generated from [Conventional Commits](https://www.conventionalcommits.org).


## [0.5.0] - 2026-10-16

### Features
- Responsive layout for tablets and phones, and a comment box that fits split diffs
- Show saved PR lists at once and refresh them in the background
- Open grain from your other devices with grain share
- Grain domain names what's blocking port 80 and doctor checks grain.localhost still reaches Grain

### Documentation
- One copyable install command per package manager



## [0.4.0] - 2026-10-15

### Features
- Review a whole PR on one page with IDE-style navigation, errors and an AI second opinion (#2)



## [0.3.0] - 2026-10-13

### Features
- Pick folders with the system picker and find clones in your work folders



## [0.2.0] - 2026-10-13

### Features
- Review a PR as a story of user flows, with a design system (#1)


## [0.1.0] - 2026-10-12

First public release: semantic review of GitHub pull requests and local changes as chapters and blocks, keyboard-first self, peer and maintainer modes, GitHub review posting with suggestions, thread replies, CODEOWNERS, a map of linked blocks, precise TypeScript usage facts, and optional AI summaries through your own agent.
