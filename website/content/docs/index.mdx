---
title: Introduction
description: grain lays out a pull request as the user flows it changes, in call order, on your own machine.
---

grain is a local code review tool for GitHub pull requests. Instead of listing files from A to Z, it groups a PR by the user flows it changes and shows each flow's code in call order. You review what a user would hit together, and routine changes come last.
