## One page

The whole PR is on a single page, like GitHub's Files tab but in [story order](/docs/guides/ordering). The file header stays pinned while you scroll, along with the chapter you're in.

- **Viewed.** Press `v` to mark a file viewed and jump to the next one you haven't viewed. Your progress is saved, so a refresh or restart doesn't lose it.
- **Split or unified.** Press `s` to switch. grain remembers your choice. New and deleted files always use the full width.
- **Review mode.** Press `1`, `2` or `3` for self review, peer review or maintainer review.
- **Your code first.** Press `m` to move files you own under CODEOWNERS into the first chapter.

## Following the code

- **Used by.** A line under each changed export lists where it's used. Chips for code inside the PR jump straight to it.
- **Go to definition.** ⌘-click a name to jump to its definition. Press `b` to return to where you were.
- **Command palette.** `⌘K` jumps to any file or runs a command.

## Comments

Click or drag across line numbers to comment on one or more lines. You can also suggest an edit, reply to existing GitHub threads, and resolve them. Replies and resolves are sent immediately. New comments stay as drafts until you finish.

## Finishing

Press `Shift Enter` to finish. Choose comment, approve or request changes, and grain posts everything as a single GitHub review.
